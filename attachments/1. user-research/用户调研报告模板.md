# 用户调研报告模板

**用途：可复用的空白模板。** 将方括号替换为本轮材料，删除无关提示；无证据时写“待确认”。方法详见 [怎么做用户调研](怎么做用户调研.md)。

报告主题：[ ]　调研日期：[ ]

正文只保留影响判断的内容。同一事实只在一处展开，摘要点到结论即可；背景、详细记录和追问放附录。

## 1. 核心结论

用三句话回答：发现了什么、优先验证什么、结论有什么限制。

本轮围绕 [研究问题]，研究了 [样本数量、对象与场景]，发现 [最重要的行为或问题及其影响]。

建议优先 [一项行动或验证]，重点判断 [是否值得继续投入的关键问题]。

当前结论适用于 [范围]，尚不能确认 [最可能改变决定的未知]。

## 2. 现状流程

流程依据：[案例或材料编号；单次经历 / 多个案例核对后的常规流程]。

多类任务按场景对比；单一任务按关键步骤填写，不强行拆场景。

| 任务 / 步骤与触发条件 | 输入、工具与关键操作 / 判断 | 产出与用途 |
| --- | --- | --- |
| [谁在什么情况下开始做] | [用什么资料、怎样处理、依据什么选择] | [交给谁、用于什么决定或行动] |
| [下一步或另一场景] | [同上] | [同上] |

将真实的交接、等待、返工写入对应环节，只保留影响判断的分支。仅有问卷、无法还原具体步骤时，写已确认的行为路径和依据，缺失环节留待确认。

## 3. 关键发现

通常保留最影响决定的 2–3 条，证据少时不凑数。每条写一个结论；流程表已列出的操作无需复述。

### 发现 [编号]：[具体行为或问题及其影响]

**事实与证据：**[原话、观察、记录或统计结果，附证据编号；必要时补充现有办法、频率、影响或反例]。

**含义 / 待验证假设：**[这些事实说明什么、可能的原因；明确哪些是研究者推断，不在此展开解决方案]。

所有时间、成本和效果数字就地注明过去 / 现在、估计 / 实测及比较条件。结论存在特定适用条件或反例时，就地说明；跨发现的关键证据缺口集中写在下一节，不逐条重复。

## 4. 下一步验证

**关键证据缺口：**[用一句话说明当前最影响决定的证据缺口；具体追问放附录]。

围绕优先方向，通常用三步说明怎样取得证据并作出决定；按实际需要增减。选择现有工具、流程调整、商品改进或新增能力时，依据研究发现说明理由，不默认必须做新功能。

| 动作与目的 | 对应发现 | 判断标准 |
| --- | --- | --- |
| [补齐关键证据：拿什么材料、补访谁或观察什么] | [编号] | [补齐后能确认或排除什么] |
| [核实问题与基线：还原哪段过程、测量什么影响] | [编号] | [如何判断问题及影响是否成立] |
| [比较改进效果：用什么真实任务、样本或条件做验证] | [编号] | [什么结果支持继续、调整或停止；计入核查、修改等实际成本] |

负责人和时间仅在已确认时添加；尚未确定的数值标准写明需先取得什么基线。“愿意用”属于意愿，提效或商品改进效果需实际试用或业务数据支持。

## 附录（按需保留）

- **背景与方法：**为什么调研、研究问题、对象及样本来源；记录影响判断的角色、市场、工作量、目标和资源限制。注明实际采用的方法及样本覆盖边界。
- **证据来源：**按编号列访谈记录、原始材料、观察或试用记录；注明时间和材料性质，正文引用编号。
- **待补材料与追问：**补充正文验证动作需要的具体资料和访谈问题；其他场景的线索单列，避免混入本轮结论。
- **问卷与详细记录：**附题目、选项、原始统计及完整流程。问卷注明发放范围、回收数、有效样本及筛选规则；正文统计写“选择人数 / 本题有效回答人数（比例）”，注明题目、人群和时间范围。跳过、未答与“不适用”分开记录，样本比例不直接推及行业。

**交付前检查：发现有证据，推断有标识，建议对应发现，验证能改变决定；删除重复解释和未填写的提示。**

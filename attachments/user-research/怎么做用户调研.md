# 怎么做用户调研

用研要弄清：**谁在什么情况下，怎样完成工作，哪里困难，造成什么影响，是否值得解决。**

## 开始前

- 先明确调研背景：**探索新场景**，了解用户、任务与现有办法；**迭代已有场景**，找到卡点、原因和改进空间。
- **先访谈亲自做这项工作的人。** 研究交接时，再问接手的人。例如，先问运营如何提出改图要求，再问美工收到的资料是否够用。
- 按本次任务选择需要了解的背景，结合具体经历追问：

| 记录什么 | 为什么了解 | 例子与追问 |
| --- | --- | --- |
| 岗位与决策分工 | 分清谁操作、谁提供信息、谁拍板。 | **选品：**开发找款、采购对接工厂。“最近这款是谁提出、谁验证、谁决定进货？” |
| 平台、市场与人群 | 了解卖给谁、在哪使用，以及语言要求。 | **选品：**日本站、小户型收纳盒。“为什么选这群人？他们现在用什么，哪里不满意？” |
| 品类、规格与规模 | 确认比较标准和实际工作量。 | **选品：**比较 5 款收纳盒；**运营：**跟踪 20 个 SKU。“候选怎么来？哪些规格能放在一起比？” |
| 商品阶段与目标 | 了解为什么现在做、怎样算做好。 | **改品：**减少包装破损；**升级：**增加折叠功能。“具体改哪里？最想改善什么结果？” |
| 需求或问题依据 | 确认改动由什么触发。 | **改品：**收到破损反馈。“最近一次发生了什么？反馈来自谁？怎么判断问题出在哪里？” |
| 供应链与成本约束 | 了解改动、预算、打样和交期的限制。 | **升级：**折叠结构需重新打样。“工厂能改哪里？成本、起订量怎么变？怎样决定是否量产？” |
| 履约与责任分工 | 找到仓储、运输及异常处理的责任人。 | **改品：**海外仓发货后出现破损。“发生在哪个环节？谁有记录？改完由谁检查？” |

**分清研究对象：**研究 AI 选品等业务工具，访谈实际参与工作的人员；判断商品该怎么选或改，还要了解目标消费者的真实购买和使用经历。运营意见与评论可作为线索，需求仍需核实。

## 选访谈还是问卷

| 方式 | 适合弄清什么 | 能挖多深 | 结论能说明什么 |
| --- | --- | --- | --- |
| 1v1 深度访谈 | 工作怎么做、依据什么判断、哪里卡住。 | 能追问、看操作、核对材料。 | 可深入理解具体案例；问题在整个人群中有多普遍，需要更多证据。 |
| 线上问卷 | 行为频率、偏好及不同群体的差异。 | 统一收集便于比较，难以当场澄清回答。 | 先描述答卷样本；能否代表目标人群，要看样本从哪里来、覆盖了谁。 |

**置信度，就是对某条结论有多大把握。** 看是否找对人、问清问题，以及有没有操作或记录支持。人数多也可能样本偏：例如，卖家群的 100 份答卷中有 60 人认为报表耗时，不能直接写成“60% 的跨境运营都有这个问题”。

按问题组合方法：新场景可先访谈发现问题，再用问卷了解分布；已有场景可先问卷找差异，再访谈解释。若要证明提效或商品升级的效果，还需实际试用或业务数据，不能只看“愿意用”。

## 访谈时的建议

1. **先看全貌，再深入一次经历。** 日常工作看一天或一周，选品、改品、升级看最近一个项目。例如：“最近一次定款，从候选怎么来，到谁拍板，带我走一遍。”

2. **把模糊动作问具体。** 听到“分析、优化、处理”，追问输入、依据和动作。做报告时问：“挑一条结论，看用了什么数据、最后改了什么。”升级要“更耐用”，就问：“原款出了什么问题？有哪些反馈或退货记录？”

3. **由研究者还原流程。** 默认对方没有流程图，从第一步问起，记录判断、交接、等待和返工，再请对方纠正。竞品与关键词跟踪混在一起时，先确认当前任务，再请她演示；选品打样时问：“谁验样？结果交给谁？怎样影响定款？”

4. **问清比较口径。** 区分过去与现在、估计与实测。用了八爪鱼后问：“还有哪些人工步骤，各花多久？前后 SKU 和任务一样吗？”比较升级款时问：“测试条件一样吗？性能和成本分别变了多少？”

5. **主动找不同情况。** 用相反案例检查自己的解释。例如：“有没有一次竞品排名变了，你却决定不调整？为什么？”

6. **把方案放在后面。** 先了解现有办法，再用真实任务试方案。报告生成后，观察还需补查、修改什么；商品升级时，让目标用户用新旧收纳盒完成同一任务，再问：“哪些变化有用？你会怎么选？”

## 万能问题

按回答选问，无需逐条问完。

| 想弄清什么 | 设计问题的思路 | 可以怎样问 |
| --- | --- | --- |
| 目标 | 找触发事件和完成标准。 | 最近一次为什么开始做？做到什么程度算完成？ |
| 流程 | 沿一次经历，追输入、动作和交接。 | 先做了什么？拿到结果后，接下来谁做什么？ |
| 判断 | 追真实选择、备选方案和依据。 | 最近一次选品，为什么选 A、放弃 B？ |
| 困难 | 先问具体事件，再分开问频率和后果。 | 最近一次哪里卡住？过去一个月发生过几次？影响了什么？ |
| 替代办法 | 问已经尝试的办法及剩余问题。 | 现在怎么解决？用了工具后，还要手工做什么？ |
| 结果 | 追产出用途和效果证据。 | 交给谁？对方做了什么？怎么判断有没有做好？ |
| 例外 | 找不同结果，检查成立条件。 | 有没有一次作出了相反决定？当时有什么不同？ |
| 取舍 | 加入资源限制，了解优先级。 | 如果只能先改善一处，你选哪里？为什么？ |

**转成问卷时：**先确认答题者符合研究对象；未做过相关任务的，跳过经历细节题。每题只问一件事，明确时间和对象。例如，围绕最近一次竞品数据整理，分别问“处理了多少个竞品？”“主动操作了多少分钟？”“用了哪些工具？”。

单选项应不重叠、覆盖合理情况，必要时提供“不适用／记不清”；先请目标用户试填，检查题意、选项和跳题是否清楚。

## 访谈后

先整理一条实际路径：**触发 → 输入 → 操作与判断 → 交接或执行 → 结果**，补上分支和回头路，再核对。

只有一次经历就写“单次案例流程”；比较其他案例后，再提炼常规流程。记不清的地方留“待确认”。

记录分开写：**对方说的 / 现场看到的 / 材料证明的 / 自己推测的**。耗时注明估计或实测；每条发现写清证据、适用人群和仍待确认的部分。

# 亚马逊精品运营工作台 · MVP

Day 09 的独立实现。Day 05 的原始 `index.html` 保持不动。第一版只做四步：

**数据导入 → 数据报告 → AI 分析 → 日报导出**

不包含店铺管理、运营待办或复杂的工作空间设置。打开页面不自动填充模拟数据，可以导入新资料或恢复上次保存的资料。

## 本机启动

当前电脑已安装依赖、初始化数据库。进入本目录运行：

```sh
npm run dev
```

打开终端显示的地址，默认是 http://localhost:5173/ 。已有预览运行时不要重复启动。

在一台新电脑上需要 Node.js 22.13 或更新版本，先运行 `npm ci`，再运行 `npm run build`。仅在全新本地数据库上执行一次：

```sh
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_wet_talisman.sql
```

然后运行 `npm run dev`。本地预览使用脚手架的回环地址模拟身份，无需另外注册账号。资料、修改和原始文件保存在本项目的 `.wrangler/state`，不提交 Git；不要删除它，否则会丢失本地记录。

## 怎么用

1. **数据导入**：选择文件、粘贴内容，或通过「MCP 数据源」读取外部资料；核对原文、表格和指标映射后确认。也可点击“恢复上次数据”。
2. **数据报告**：切换表格、筛选数据；添加或修改图表的类型、坐标、指标叠加、目标线及备注。文字资料可直接修正。
3. **AI 分析**：在当前页修改分析 Prompt，生成后直接编辑分析结果；可下载 Markdown，也可带入日报。
4. **日报导出**：修改日报 Prompt、生成草稿并编辑正文；下载 Markdown / HTML，或通过打印对话框另存 PDF。不接 AI 也能先整理数据摘要。

右上角“模型连接”配置服务商、模型名称和 API Key，不属于某一份资料。当前支持 DeepSeek API、阿里云百炼北京地域。

### 本地 API Key（刷新后仍可使用）

在“模型连接”填写密钥后点击**保存到本机**，或复制 `.dev.vars.example` 为项目根目录的 `.dev.vars` 并直接填写：

```dotenv
AI_PROVIDER=deepseek
DEEPSEEK_MODEL=deepseek-flash
DEEPSEEK_API_KEY=替换为自己的密钥
```

百炼北京使用 `AI_PROVIDER=qwen`、`QWEN_MODEL`、`QWEN_API_KEY`。模型名中的 `deepseek-flash` 使用短横线。

- `.dev.vars*`、`.env*` 已加入 Git 忽略，仅不含真实密钥的 `.dev.vars.example` 可以提交。不要使用 `VITE_` / `NEXT_PUBLIC_` 存放密钥。
- 开发服务器在项目配置中显式禁止读取 `.dev.vars*`，并保留 `.env*`、证书和 Git 内部文件的访问限制。配置文件放在项目根目录；不要放进公开的 `public/` 目录。Git 忽略规则与网页访问限制是两项独立保护。
- 本机保存入口只在本地开发服务启用，要求回环地址、已登录和同源请求；文件权限为 `0600`。如果项目已有 `.env` / `.env.local`，沿用 `.env.local`，避免新建 `.dev.vars` 屏蔽旧配置。
- 密钥只由服务端读取，不返回给浏览器，不进入资料、报告或导出文件。临时输入会覆盖当前服务商的本地密钥；留空则使用本地密钥。仅临时输入的密钥刷新后清空。
- 点击**测试连接**会发送一句“回复 OK”，验证真实模型回复，不发送导入资料，可能产生少量 API 费用；保存成功不等于授权已验证。
- 界面保存后会重载服务；手工修改文件后如未生效，重启本地服务。不要把 `.dev.vars` 与 `.env*` 混用，前者优先。构建目录同样被 Git 忽略，属于本机私有产物。
- DeepSeek 请求显式关闭思考模式，以免输出预算在分析正文前耗尽。网络、超时、余额、密钥、模型名错误会分别提示，失败后不自动重试。

## 格式与边界

### MCP 数据源：西柚洞察（xyzc-mcp）

在「数据导入 → MCP 数据源」粘贴西柚洞察控制台「凭证管理」提供的**完整 MCP 授权链接**，或填写 `https://mcp.xydc.com/mcp` 和 **Bearer Token**（不含 `Bearer ` 前缀），点击连接，选择查询类型并填写 ASIN / 关键词 / 站点 / 时间范围，然后勾选额度确认并读取预览。点击「导入这份结果」后才会保存；仍需在原校验页确认，才会参与报告。

- Codex 中的连接与独立工作台是两个客户端，不会自动共享。工作台不读取 Codex 凭证文件；链接和 Token 只保留在弹窗内存中，关闭或刷新即清空，不保存到数据库、日志、Prompt、备份或日报。Bearer Token 通过 Authorization 请求头发送，工具清单和查询结果中的原样凭据回显会被隐藏。
- 使用官方 MCP SDK 的 Streamable HTTP 握手、工具发现和工具调用，不是把普通 HTTP 接口标成 MCP。输入表单来自实时返回的参数定义。
- MVP 开放 8 种经审核的只读查询：商品基础信息、近 7 天流量、近 7 天反查关键词、日流量趋势、月订单量趋势、关键词市场指标、ABA 周趋势、关键词日排名趋势。服务端固定允许 `https://mcp.xydc.com/mcp`，拒绝其他地址、重定向和任意工具调用；不开放生成资源、反馈提交或写入动作。
- 数据查询可能消耗西柚洞察额度。没有自动轮询、翻页或重试；每次只读取用户提交的范围。取消等待也不保证平台尚未扣额度。
- 返回 JSON 中的行数组、CSV 和文字复用现有解析链路。原始响应保存为 JSON 文件；查询名称、条件、时间随资料保存。复杂嵌套保留为文字，不承诺所有返回格式都自动变成正确图表。
- 外部数据与店铺实际经营数据不同。MCP 表格不自动映射经营指标，防止把流量得分当成访客数；用户核对后再选择字段或图表。AI 证据中保留来源边界。
- 单次结果上限 1 MB；最多 20 张表、每表 5,000 行、60 列。超限报错，不静默截断，不自动扩大查询。
- 已验证授权握手和工具发现；未调用收费业务数据或验证全部返回格式。真实查询由使用者自测。

授权入口及说明：[西柚洞察接入文档](https://platform.xydc.com/docs/mcp-access)。

### 文件与报告

- Excel：XLSX / XLS，另支持 CSV / TSV、多工作表。
- 截图：PNG / JPG / JPEG / WEBP / BMP，通过英文和简体中文 OCR 识别。
- 文字：TXT / Markdown / 粘贴文字或表格。
- Word：DOCX；旧版 DOC 需要先另存为 DOCX。
- PDF：提取文字；扫描页走 OCR。OCR 需要联网加载引擎与语言包，结果需要人工核对。
- 文档和图片不保证恢复成准确的结构化表格；可作为文字材料参与分析，绘图需提供或整理成 Excel / CSV 等表格。
- 单文件最多 10 MB、PDF 最多 40 页；每份日报最多 20 份资料，每张表最多 5,000 行、60 列。
- AI 只在用户确认后调用，可能产生服务商 API 费用。尚未使用真实 Key 验证付费模型效果。
- 目前下载的日报以正文为主；PDF 使用浏览器打印，不是后台生成附件。

产品与代码分层见 [PRODUCT.md](./PRODUCT.md)。本轮界面收敛只进行编译检查，交由使用者自测，不执行复杂验收。


## Day 09：切换 AI 协作方式

在右上角“AI 交互方式”选择成果共创、任务委派、流程编排、文件式 IDE 或命令式 CLI。先导入并确认资料，所有模式共用同一份正文、模型连接、保存和导出。

- 共创 / IDE：选中文字 → 描述改动 → 审阅修改前后 → 接受；接受前不改正文，可以回退最近三次修改。
- 委派：描述目标 → AI 提出计划 → 编辑步骤并执行 → 暂停纠偏或从未完成步骤续跑 → 比较并验收成果。
- 流程：配置来源、触发、复核分支和停止 / 重试策略 → 运行。MCP 来源只读取已经导入并确认的资料；本页监听离开即停止。
- CLI：输入 `/help` 查看指令；`/ask` 问答，`/draft` 和 `/rewrite` 生成待确认建议，`/apply` 接受，`/export` 下载。这里不执行系统 Shell 命令。

这版以文字报告作为共同成果，不包含商品图重绘或任意电脑文件操作。刷新后任务不会在后台继续；执行记录可用于人工续跑。

交互逻辑与回归检查：

```sh
node --import ./tests/resolve-ts.mjs --test tests/interactions.test.mjs tests/domain.test.mjs tests/model-client.test.mjs
```

CLI 和 IDE 使用独立全屏工作区，可从顶部返回步骤式工作台。IDE 中报告、任务要求与导入资料的文字都可直接编辑和自动保存，AI 建议明确绑定当前文件；修改资料会更新证据版本。资料文字的修改不改动原始文件或已有结构化表格。

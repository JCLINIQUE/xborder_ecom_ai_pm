# Day 04｜竞品追踪工作台原型走查

打开 [可点击原型](<竞品追踪工作台-交互原型.html>)，对照 [业务版 PRD](<业务版PRD-竞品追踪工作台.md>)，用同一组资料走三条路径。原型沿用旧“资料准备”页面布局，业务改为**日常价格／促销追踪**，不沿用桌麦选品或卖点分析。配套只需本指南与一个原型，无须另填练习模板。

**演示边界：**内置资料、识读结果和模型文案均为教学模拟。按钮会改变记录、核对、分析和导出状态，但不做真实上传、OCR、模型调用、持久化或 Excel 下载；导出只展示预览。产品确定不做爬虫。不要把完成点击当成识读质量或业务效果已验证。

## ① 正常完成：从资料到可复核的解读

**资料准备 → 提取 → 核对本批记录 → 辅助分析 → 人工复核 → 导出预览。**

1. 使用正常路径，查看 Excel、旧截图 A-1-I、Word 三类资料及各自观察时间。提取后先查看候选值和来源，再核对本批记录；上传时间不能代替观察时间。
2. 在对照表确认：竞品两期标价均为 11,800 日元，自家均为 10,800；旧截图未展示券，本次展示 2,000 日元券，资格与期限未知。已核对表示与材料一致，不代表平台实时真值。
3. 点击辅助分析，核查“发现、关注理由、待核实、有条件方向”四部分及引用。9,800 是券适用时的条件计算，不能写成普遍成交价，也不能推出竞品抢走销量。
4. 编辑需要调整的表述，人工复核后查看导出预览。数据可以单独导出；只有与导出范围一致、依据未变且已复核的解读，才能附带。

老师追问：**哪一步是程序算数，哪一句是模型解释，哪项取舍仍由运营完成？**

## ② 部分失败：保留能用的数据，补回缺失证据

**旧截图识读失败 → 核对其余记录 → 看标价／辅助分析 → 单独重试旧截图 → 重新核对与分析。**

选择部分失败路径：A-1-I 失败，Excel 与 Word 仍可用。核对后，竞品标价差 0 仍可展示；旧券字段只能记为未采集，不能写成“旧时没有券”。解读只能确认本次展示券，并将补查旧记录列为优先事项。

单独重试 A-1-I。成功后应先核对补入的证据，再重新分析；先前解读不能因文件恢复就自动成为已复核。对比前后，指出哪句从“无法确认变化”变为“两个时点展示不同”。其他已核对记录不必丢弃重做。

另试课堂专用的模型失败开关：分析失败后可重试，也可跳过分析查看数据导出预览。失败不等于“未发现风险”，更不能拿预设文案冒充实际模型结果。

## ③ 修改之后：数据变了，旧解读也必须变

**从已复核状态修改 → 相关数据待核对／解读失效 → 重新核对 → 生成新候选 → 采用并复核 → 导出预览。**

先在解读中留一段人工修改，再任选一项演示：

- 将券从 2,000 改为 1,000 日元：相关字段回到待核对，旧解读显示“依据已变化”。核对后，若券适用，条件价应为 10,800，与自家标价相同；原“低 1,000”不可继续引用。
- 撤去 A-1-I：旧优惠回到未采集，无法确认前后优惠展示变化；两期标价不变仍成立。重新分析应优先要求补旧证据。

生成的新结果先作为候选，保留旧文及人工修改；查看差异后采用并复核。失效或未复核解读不能附带导出，数据预览仍可继续。人工复核解读与运营决定是否行动是两回事。

## 对照 PRD 收口

| 走查 | 功能与验收 | 最后检查 |
| --- | --- | --- |
| 正常完成 | W1–W6；AC01、AC10、AC14 | 来源可查，四段解读有条件，导出状态正确。 |
| 部分失败 | W2–W6；AC05、AC11、AC12 | 局部失败不阻断可用数据；重试后重新核对。 |
| 修改之后 | W3–W6；AC05、AC13、AC14 | 旧依据失效，人工内容保留，新结果再复核。 |

课堂只记录走查发现的规则缺口，回写同一份 PRD。以上路径覆盖的是交互预期；真实解析、模型质量与数据保存仍需后续实现和测试。

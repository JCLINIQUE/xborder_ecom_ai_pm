# 竞品对比助手｜Day 04 结构原型

> 历史 SSD 原型参考。当前 Day 04 使用 [竞品追踪工作台业务版 PRD](<业务版PRD-竞品追踪工作台.md>)；本文的页面、编号与验收不直接适用于新方案。

## 使用边界
- 教学模拟，待真实任务确认；节点表达流程，不代表功能已实现。
- 按 P1 → P2 → P3 走查，展开条件查看分支；T1–T9 对应 Day 03 验收要求。
- 首版 R1–R3；R4 为可选模拟。链接仅供回查，不抓取网页，不预设表格上传或识图。

## P1资料录入
- 页面信息（R1）
  - 入口：新建空任务／载入教学样本。
  - 商品：唯一编号、自家／竞品、站点、币种、日期、容量、形态、接口。
  - 价格：正数金额、价格口径；图片：位置、人工观察摘要。
  - 来源：材料名称或链接＋具体位置；价格编号如 A1-P，图片编号如 A1-I。
- 动作：保存商品 → 条件判断
  - 编号空或重复、自家超过一个、价格非正数 → 就地提示，保留其余输入。
  - 字段或来源不全 → 允许保存，逐项标“待补”；不把未知填成正常值。
- 动作：生成对比 → 条件判断（T1）
  - 未设置一个自家商品或没有竞品 → 提示补齐，留在 P1。
  - 身份齐全 → 前往 P2；个别商品缺项不阻断其他比较。

## P2对比与复核
- 页面信息（R2、R3）
  - 价格和图片分区；每项显示判断、原因、来源、保留／排除。
  - S1：9,800 日元；A1：8,980 日元，同日日本站、同币种、同为 1 TB／2.5 英寸／SATA、含税标价。
- 动作：查看价格 → 条件判断（T2–T4）
  - 同站点、币种、日期、容量、形态、接口，均为含税标价且来源齐全 → A1 可比，8,980－9,800＝－820，比自家低 820 日元。
  - B1 为 2 TB → 容量不同，本轮不直接比较，不计算价差。
  - C1 无已知冲突，但缺接口、形态、价格条件 → 列待补项；A1 比较保持可用。
  - 自家基准字段缺失 → 所有依赖该字段的价格比较待补。
- 动作：查看图片 → 条件判断（T3–T4）
  - 双方图片位置、人工摘要、来源齐全 → 并列观察。
  - B1 规格不同 → 仍可作表达参考，展示站点与规格差异；参数不可照搬。
  - C1 无图片资料 → 仅列待补，不编内容，不影响 A1 价格比较。
- 动作：回查与修改 → 条件判断
  - 点价格来源 P／图片来源 I → 显示材料和位置；运营判断是否支持内容。
  - 修改 A1 标价为 10,000（T5）→ 价差重算为＋200；清除旧草稿和整体确认。
  - 排除该条价格比较并填理由／恢复保留 → 只影响价格区域，取消确认；恢复前仍需符合价格口径。
  - 排除该条图片参考并填理由／恢复保留 → 只影响图片区域，取消确认；恢复前仍需有有效观察和来源。
- 动作：生成草稿（可选 R4、T8）→ 条件判断
  - 首次成功 → 显示“模拟草稿／未复核”，分观察、可能解释、候选动作、待核查。
  - 已有草稿 → 提示成功后替换且覆盖人工修改；取消保留原文，成功替换后取消确认。
  - 失败 → 保留资料、对比表、已有草稿；可重试或手动继续。
  - 来源编号不存在 → 标错误；相关事实须补证、删除或移入待核查，不能直接确认。
- 动作：整理结果 → 前往 P3；来源能回查不等于结论成立，因果解释仍需人工判断。

## P3整理与导出
- 页面信息（R3）
  - 预览实际保留的对比、来源、结论、排除原因和待核查项。
  - 下一步：用于讨论／暂不行动／继续补资料；填写理由。
- 动作：编辑或返回修改 → 反馈（T5、T9）
  - 改结论、排除选择或决定 → 取消整体确认，提示重新复核。
  - 返回 P1 改源资料 → 重算相关结果、清除旧草稿和确认，再走 P2。
- 动作：整体确认并导出 → 条件判断（T6–T9）
  - 保留至少一组有效价格比较或有来源的图片对照＋决定及理由＋整体确认 → 导出 Markdown。
  - 保留 A1 有效对照、C1 仍缺项，选择暂不行动并说明理由 → 可确认导出，附 C1 待核查项。
  - 没有有效对照或排除最后一组 → 提示暂无可用对比及具体原因，不能导出空报告。
  - 未填决定或未重新确认 → 显示待完成项，完成后再导出。
  - 两类对照都缺来源（T7）→ 提示补来源，返回 P1；不导出无依据事实。

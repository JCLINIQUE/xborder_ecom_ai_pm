# 页面与交互说明｜竞品对比助手

旧版 SSD 原型教学示例，待与当前业务版 PRD 衔接。配套：[Day 04 指南](<Day04原型设计指南.md>)

本说明用于 Figma 画框、XMind 节点和原型走查，状态变化采用教学模拟。三张 SVG 展示代表状态，下面的其余状态需在选定工具中补画或明确展开。

## 1. P1｜资料录入（R1）

线框：[P1-资料录入.svg](<wireframes/P1-资料录入.svg>)

**信息顺序：**任务入口及模拟标识 → 商品清单与角色 → 所选商品字段 → 价格／图片来源 → 保存与生成对比。

- 顶部提供“新建任务”“载入教学样本”；只有后者带入 S1/A1/B1/C1，始终显示模拟标识。
- 列表区显示商品编号、自家／竞品、资料状态。自家只有一个；缺字段的记录保留在列表中。
- 编辑区包含站点、币种、日期、容量、形态、接口、价格口径和金额，以及人工填写的图片位置与摘要。
- 价格、图片各有来源记录：材料名称或链接＋具体位置。S1-P、S1-I 等来源编号单独显示；查看链接不表示自动获取资料。
- “保存资料”接受缺项；编号为空或重复、金额非法时定位错误并保留其余输入。“生成对比”缺自家或无竞品时显示具体原因，留在 P1。

**C1 示例：**缺接口、形态及价格口径，用文字逐项列出；不能只显示一个红点。“补资料”返回本页时应直接定位 C1，避免用户重新找记录。

## 2. P2｜对比与复核（R2，可选 R4）

线框：[P2-对比与复核.svg](<wireframes/P2-对比与复核.svg>)

顶部固定自家 S1 的比较口径。价格与图片分两个区域，每个状态都带原因，颜色只作辅助提示。

| 区域 | 模拟数据与状态 | 操作及范围 |
| --- | --- | --- |
| 价格比较 | A1 8,980，自家 9,800，价差 -820；B1 容量不同不算价差；C1 待补信息。 | 回查价格来源、修改资料、排除此条价格对比并写理由。 |
| 图片表达 | A1 图 2 与自家图 5 的观察；B1 设备图示作为表达参考；C1 无图片记录。 | 回查图片来源、修正观察、排除此条图片参考。规格和站点差异同时呈现。 |
| 结论草稿（选做） | 未生成、生成中、未复核草稿、失败或无效引用。 | 生成／重试、编辑、删除、核对引用；失败仍可手动继续。 |

“排除价格比较”和“排除图片参考”分别作用于各自区域；排除 A1 的价格不自动删除其图片参考。已排除项可“恢复保留”，但仍需满足当前用途的条件；B1 原本就不符合价格口径，不能用恢复或手动勾选绕过规则。恢复选择也会取消整体确认。

“查看来源”打开详情浮层或子主题，显示材料名称、具体位置和可选链接，关闭后回原处。“补充／修改资料”回到 P1 对应商品；仅查看来源或往返页面不取消确认，真正修改后才取消。

“整理导出”只是进入 P3 的导航入口，不等于执行导出；尚未确认时也可以进入 P3 查看缺哪些条件。

## 3. P3｜整理与导出（R3）

线框：[P3-整理与导出.svg](<wireframes/P3-整理与导出.svg>)

**信息顺序：**保留的对比及结论预览 → 来源与待核查项 → 下一步决定与理由 → 整体复核确认 → 导出按钮。

结论按观察事实、可能解释、候选动作、待核查项区分，支持编辑和删除。用户修改事实结论时，应同步核对它是否仍有来源支持。

导出需同时满足：保留至少一组有效价格比较或有来源的图片对照；填写下一步决定与理由；确认本次保留内容。按钮不可用时直接列出未满足的条件，不能只变灰。

**代表状态：**S1/A1 已能比较、C1 待补，决定为“暂不行动”且已写理由，但确认框未勾选。此时仅提示“请复核并确认本次保留内容”；不要求补齐 C1 才能导出。

修改资料、结论、排除选择或下一步决定后取消本次确认。源资料修改还会清除旧草稿、更新对比。最后一组有效对照被排除时，即使重新确认，也不能导出空材料。

## 4. 按钮、分支与验收对照

下表是需要画出的状态及连线。Figma 可用复制画框模拟，XMind 用条件节点表达；不要求原型阶段实现真实计算或下载。

| 验收 | 起点与动作 | 反馈、去向与恢复 |
| --- | --- | --- |
| T1 | P1-empty：未设自家，点击生成对比。 | 留在 P1，提示设置自家；补齐后才能进入 P2，已填资料保留。 |
| T2 | P1-filled：载入样本并生成。 | P2-mixed：A1 显示比自家标价低 820，来源能展开。 |
| T3 | P2-mixed：查看 B1 的两个区域。 | 价格解释容量不同，图片仍为参考；两类排除入口独立。 |
| T4 | P2-mixed：点击 C1 补资料。 | 回 P1 定位 C1；缺项保留，其他可用比较不受阻碍。 |
| T5 | 已确认后返回 P1，把 A1 改为 10,000 并保存。 | P2-updated：价差 +200、旧草稿清除、取消确认；P3 导出待重新复核。 |
| T6 | P3-unconfirmed：保留 A1 比较和 C1 待补，选暂不行动并写理由，完成确认。 | P3-confirmed：导出可用；连接到包含决定、来源和待补项的结果预览。 |
| T7 | 唯一竞品两类来源均缺失。 | P2-none／P3-blocked：暂无有效对照，提示补来源，导出不可用。 |
| T8（选做） | P2-AI：生成失败，或草稿含不存在的来源编号。 | 显示错误，保留原资料和已有草稿；失败可重试或手动继续，无效引用需修正后才能确认。 |
| T9 | P3-confirmed：编辑结论，或回 P2 排除最后一组有效对照。 | 编辑后回未确认；有效对照变为零时，显示阻碍并引导恢复选择或补资料。 |

选 R4 时另补“重新生成”提示：会覆盖当前草稿及其中的人工修改；取消保留原文，生成成功后重新复核。此分支不得直接连接到“已确认”。
